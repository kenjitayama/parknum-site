# parknum-site

Website for ParkNum, an iPhone app that remembers your parking spot number.

https://kenjitayama.github.io/parknum-site/

- `ja/`, `en/` — app intro
- `ja/support/`, `en/support/` — support and FAQ
- `ja/privacy/`, `en/privacy/` — privacy policy

Plain static HTML and CSS served by GitHub Pages from `main`. No build step, no external resources, no trackers.

Questions and bug reports: [Issues](https://github.com/kenjitayama/parknum-site/issues).
